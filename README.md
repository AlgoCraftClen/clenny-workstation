# clenny-workstation
Clenny’s personal multi-venture accounting and decision workstation.

The app requires the authorized Clenny Supabase session for every ledger read and write. It receives shared shipment, operation, sale, and capital-adjustment changes through Supabase Realtime, with manual refresh and bounded polling as recovery fallbacks.

The SHP #4 → SHP #5 $50.63 difference is held as a business reserve pending a partner decision. This temporary shared classification changes neither cash nor ownership.
